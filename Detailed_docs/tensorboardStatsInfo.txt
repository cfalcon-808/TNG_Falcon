"""
------------------------------------------------------------
PPO TRAINING METRICS – QUICK REFERENCE
------------------------------------------------------------

1. approx_kl
   - Measures how much the updated policy changed compared
     to the previous one.
   - Interpretation:
     - 0.01 to 0.03 → healthy, stable learning
     - Above 0.05 → updates too aggressive
     - Below 0.005 → learning may be too slow or stuck

2. clip_fraction
   - Percentage of policy updates that were clipped by PPO.
   - Interpretation:
     - 10% to 30% → normal
     - Above 40% → policy changing too fast
     - Below 5% → weak learning signal

3. clip_range
   - PPO clipping threshold (a constant hyperparameter).
   - Usually 0.2; not a diagnostic metric.

4. entropy_loss
   - Negative entropy (reported as a loss).
   - Interpretation:
     - More negative → more exploration
     - Moves toward zero as the policy becomes more deterministic

5. explained_variance
   - Measures how well the value function predicts returns.
   - Interpretation:
     - 1.0 → perfect prediction
     - 0.0 → predicts nothing
     - Negative → worse than predicting the mean (bad)

6. learning_rate
   - Current optimizer learning rate.
   - Typical PPO value: 0.0003

7. loss
   - Combined PPO loss (policy + value + entropy).
   - Not directly meaningful by itself; look for smooth trends.

8. n_updates
   - Number of PPO update cycles completed.
   - Indicates overall training progress.

9. policy_gradient_loss
   - Raw loss from the policy gradient update.
   - Interpretation:
     - Usually negative
     - Large magnitude → unstable updates
     - Small magnitude → weak learning

10. value_loss
    - Error from fitting the value function.
    - Interpretation:
      - 0.1 to 1.0 → normal
      - Above 5 → value network struggling
      - Very low → possible underfitting

------------------------------------------------------------
ROLLOUT STATISTICS
------------------------------------------------------------

11. ep_len_mean
    - Mean episode length over the last rollout batch.
    - Indicates how long episodes tend to last.
    - Interpretation:
      - Increasing → episodes run longer (often survival strategies)
      - Decreasing → agent fails earlier
      - Stable → consistent gameplay duration

12. ep_rew_mean
    - Mean episode reward over the last rollout batch.
    - Shows overall reward improvement trends.
    - Interpretation:
      - Increasing → agent learning good strategies
      - Flat → plateau in policy performance
      - Decreasing → possible instability or bad reward shaping

------------------------------------------------------------
TIME STATISTICS
------------------------------------------------------------

13. fps
    - Steps per second during training.
    - Higher FPS → faster training.
    - Affected by environment complexity and CPU load.

14. iterations
    - Number of PPO training iterations completed.
    - One iteration = one full update cycle.

15. time_elapsed
    - Total wall-clock time since training started (seconds).

16. total_timesteps
    - Total environment steps collected so far.
    - Main measure of training progress for RL.

------------------------------------------------------------
SUMMARY
------------------------------------------------------------
- approx_kl shows update stability.
- clip_fraction shows how often PPO clips updates.
- entropy_loss tracks exploration.
- explained_variance shows value model quality.
- value_loss shows difficulty of fitting returns.
- ep_len_mean and ep_rew_mean summarize recent gameplay.
- fps, iterations, time_elapsed, and total_timesteps track
  training speed and progress.

Healthy PPO signs:
- approx_kl between 0.01 and 0.03
- clip_fraction around 20 percent
- entropy losing magnitude over time
- explained_variance trending toward 1.0
- value_loss stable
- ep_len_mean and ep_rew_mean improving or stabilizing
------------------------------------------------------------
"""
