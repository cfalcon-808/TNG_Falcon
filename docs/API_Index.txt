============================================================
API INDEX - env_tng_falcon.py (Unified env: greedy OR smart tiger)
============================================================

CONSTANTS / ENUMS
    BOARD_SIZE, DIR_CODES, TOTAL_GOATS_TO_PLACE, GOATS_EATEN_FOR_TIGER_WIN, ...
    TIGER_AI_GREEDY = "greedy"
    TIGER_AI_SMART  = "smart"
    VALID_TIGER_AI  = {TIGER_AI_GREEDY, TIGER_AI_SMART}

DICTS (TUNING)
    DEFAULT_KNOBS
        Base magnitudes/constants (terminal rewards, step costs, shaping terms, limits, bias knobs).
    NOTE:
        reward_weights passed to TnGEnv can override keys in DEFAULT_KNOBS
        via env._w(key) resolution.

TOP-LEVEL HELPERS
    smart_tiger(...)
        Heuristic tiger policy (anchors, roaming, capture priority).
    idx_to_coord(idx)
        Map board index to human-readable coord label.

CLASS TnGEnv
    Full Tigers & Goats Gymnasium env:
        - placing phase + moving phase
        - action masking (MaskablePPO-friendly)
        - repetition / stall detection
        - reward shaping/tuning via DEFAULT_KNOBS
        - unified tiger opponent selection (greedy or smart) via tiger_ai

    METHOD __init__(reward_weights=None, tiger_ai=TIGER_AI_GREEDY, ...)
        Configure spaces, board state, counters, caches, and opponent selection.
        Validates tiger_ai in VALID_TIGER_AI; applies reward_weights overrides.

    METHOD get_action_mask()
        Return legality mask for (pos, dir) actions (flattened size BOARD_SIZE * DIR_CODES).

    METHOD reset(seed=None, options=None)
        Reset board/state/shaping; rebuild valid moves and mask.

    METHOD get_state()
        Return observation vector (flattened board + counters + phase).

    METHOD render(...)
        ASCII board with optional coordinates and status line.

    METHOD step(action)
        Normalize action (flat or MultiDiscrete) -> (pos, dir); apply goat action;
        apply tiger response (greedy or smart); compute shaping + terminal checks; return:
            obs, reward, terminated, truncated, info
        info includes info["winner"] on terminal outcomes, action_mask, tiger_ai tags.

    METHOD _select_tiger_move(...)
        Dispatch to smart_tiger or _greedy_tiger_move.

    METHOD _greedy_tiger_move(...)
        Capture-biased random tiger policy with BASE_TIGER_CAPTURE_BIAS.

    METHOD _tiger_moves(...)
        Enumerate tiger legal moves/captures.

    METHOD _update_valid_moves()
        Recompute goat actions for current phase; update mask source.

    METHOD _compute_unreachable_safe_cells()
        Tiger-unreachable bubble count via BFS.

    METHOD _precompute_all_pairs_dist()
        Precompute shortest paths on board graph.

    METHOD _shortest_path_len(start, goal)
        Cached hop distance lookup.

    METHOD _tiger_spread()
        Pairwise tiger spread metric.

    METHOD _w(key)
        Resolve knob value:
            - checks reward_weights/knob override first
            - then DEFAULT_KNOBS


CLASS FlattenTnGActionWrapper
    Wraps TnGEnv to expose Discrete(BOARD_SIZE * DIR_CODES) instead of MultiDiscrete([23, 5]).

    METHOD __init__(env)
        Set flat action space; forward observation_space.

    METHOD get_action_mask()
        Forward action mask from base env.

    METHOD step(action)
        Convert flat action index -> (pos, dir_code) MultiDiscrete, then step base env.

    METHOD reset(seed=None, options=None)
        Forward reset.


============================================================
API INDEX - eval_falcon.py (Debug + Evaluation CLI)
============================================================

CLI / MODE PARSING
    FUNCTION parse_cli_args()
        Parses up to two positional args:
            python eval_falcon.py
            python eval_falcon.py model.zip
            python eval_falcon.py normal
            python eval_falcon.py normal model.zip
            python eval_falcon.py battle
            python eval_falcon.py battle model.zip

        Behavior:
            - "normal"/"greedy" -> tiger_ai = TIGER_AI_GREEDY
            - "battle"/"smart"  -> tiger_ai = TIGER_AI_SMART
            - one arg ending in ".zip" is treated as MODEL_PATH (mode defaults to greedy)

LOGGING UTILITIES
    CLASS Tee
        Mirror stdout to multiple streams.
        METHOD __init__(streams)
        METHOD write(data)
        METHOD flush()

    FUNCTION build_log_path(model_path)
        Build log filename under artifacts/logging/eval_debug/.

    FUNCTION setup_logging(log_path)
        Open log file, install Tee on sys.stdout, return original stdout + handle.

MODEL RESOLUTION
    MODELS_DIR default = "artifacts/models/experiment" (legacy path).
    FUNCTION load_latest_model_path(models_dir)
        Find most recent .zip model in the models directory.

ENV BUILDERS
    FUNCTION _mask_fn(env)
        Return env.unwrapped.get_action_mask() for ActionMasker.

    FUNCTION make_debug_env(seed)
        Env pipeline:
            BaseEnv(tiger_ai=...) -> FlattenWrapper -> Monitor -> ActionMasker (+ seed)

    FUNCTION make_eval_env()
        Env pipeline:
            BaseEnv(tiger_ai=...) -> FlattenWrapper -> ActionMasker

DEBUG / EVAL RUNNERS
    FUNCTION decode_flat_action(flat_action, dir_codes)
        Map flat index -> (pos, dir_code).

    FUNCTION run_debug_episodes(...)
        Load model; run deterministic debug episodes with renders, masks, decoded actions.

    FUNCTION classify_outcome(reward, info)
        Determine winner label using info["winner"] or reward thresholds.

    FUNCTION run_batch_evaluation(...)
        Run N evaluation games; tally Goat/Tiger/GoatTimeout/StallTimeout,
        compute avg reward/length; print detailed + condensed summary.

MAIN
    Resolve tiger_ai + model path (default: latest), set up logging,
    run debug episodes, then run batch evaluation (logs under artifacts/logging/eval_debug/).


============================================================
API INDEX - train_falcon.py (MaskablePPO training suite: EXPERIMENT suite of VARIATIONS)
============================================================

NAMING / DIRECTORY LAYOUT
    EXPERIMENT_NAME
        Suite identifier (collection of variations).

    CORE
        Matchup tag from core_tag(), e.g.:
            "GvNT" = goat learner vs greedy/normal tiger
            "GvST" = goat learner vs smart tiger
            "MixT" optional suffix when mix_prob used (core_tag mix=True).

    Output paths:
        LOG_DIR   = artifacts/logging/train/{ALGO_TAG}/{CORE}/{EXPERIMENT_NAME}
        MODEL_DIR = artifacts/models/train/{ALGO_TAG}/{CORE}/{EXPERIMENT_NAME}

    TensorBoard run name per phase:
        {ALGO_TAG}_{CORE}_{variation}_p{phase_index}

CONFIG / CONSTANTS
    DEVICE_MODE ("gpu"/"cpu"), NUM_CPU, TIMESTEPS, PPO hyperparams, CHECKPOINTS_PER_RUN.
    ALGO_TAG, ENV_VER, MODEL_VER for labeling.

HELPERS
    FUNCTION core_tag(learner_role, tiger_ai, mix=False)
        Return matchup tag (GvNT/GvST/etc), with optional mixed flag.

    FUNCTION mask_fn(env)
        Return env.unwrapped.get_action_mask() for ActionMasker.

    FUNCTION tiger_code(tiger_ai)
        Convert tiger_ai string -> int id.

    FUNCTION tb_add_text(model_obj, tag, text, step)
        Optional TensorBoard text helper (safe no-op if unavailable).

    FUNCTION resolve_resume_path(path)
        If path is file, return it; if directory, pick newest .zip; else None.

    FUNCTION unique_filename(directory, base_name, ext=".zip")
        Produce non-colliding filename with numeric suffixes.

    FUNCTION log_phase_meta(model_obj, tiger_ai, mix_prob)
        Log phase metadata (mixed flag, tiger id, mix prob if present).

CALLBACKS
    CLASS EpisodeCounterCallback (BaseCallback)
        Logs cumulative episode count.

    CLASS WinStatsCallback (BaseCallback)
        Tracks cumulative + rolling-window goat/tiger/timeout/stall rates.

    CLASS RealizedTigerStatsCallback (BaseCallback)
        Tracks realized greedy/smart fractions when mix_prob is used.

    CLASS TigerMixWrapper (Monitor)
        Re-samples tiger_ai on every reset using a provided sampler (for mix_prob).

ENV FACTORY
    FUNCTION make_env(rank, seed, reward_weights, tiger_ai=None, mix_prob=None)
        Builds env:
            BaseEnv(reward_weights=..., tiger_ai=_sample_ai())
            -> optional TigerMixWrapper if mix_prob set
            -> FlattenTnGActionWrapper
            -> ActionMasker
            -> seed per worker

VARIATIONS / PHASES
    VARIATIONS values can be:
        None or dict (single-phase, allow inline timesteps/tiger_ai/mix_prob/checkpoints_per_run)
        list of dict phases:
            keys: timesteps, tiger_ai, mix_prob, reward_weights, checkpoints_per_run

CORE RUNNER
    FUNCTION run_single_variation(variation_name, reward_weights)
        - Build SubprocVecEnv(NUM_CPU)
        - Configure MaskablePPO (policy net [256,256,256], shared hyperparams)
        - Apply callbacks (checkpoints, win stats, episode counts, realized tiger stats)
        - Save checkpoints:
            cp_{ALGO_TAG}_{CORE}_{variation}_*.zip
        - Save final model:
            {ALGO_TAG}_{CORE}_{variation}_p{last_phase}.zip (auto-suffixed)
        - Return summary dict of rates and path.

MAIN
    Prints EXPERIMENT suite header, then iterates VARIATIONS in order:
        for variation_name, weights in VARIATIONS.items():
            run_single_variation(variation_name, weights)
    Prints sweep summary table at end.


============================================================
API INDEX - tng_GUI_falcon.py (Tkinter live play + model + replay)
============================================================

CLI
    python tng_GUI_falcon.py --env {normal|battle} [--model path/to/model.zip] [--replay replay.json]
        --env normal  -> greedy tiger
        --env battle  -> smart tiger
        --model       -> optional MaskablePPO goat model (.zip) for auto-play
        --replay      -> optional replay JSON to browse instead of live env

HELPERS
    pack_action_flat(pos, dir_code) / unpack_action_flat(flat)
        Flatten/unflatten (pos, dir) to match Discrete action space used in training.

CLASS ReplayTimeline
    __init__(source)
        Load timeline from JSON path or in-memory dict; stores timeline/final, builds reward prefix sums.
    current_board()
        Return board for current index.
    cumulative_reward(idx)
        Prefix reward sum up to idx.
    step(delta)
        Move replay index forward/backward with bounds checks.
    info_text()
        Human-readable status for current replay frame.

CLASS TigersGoatsGUI
    __init__(tiger_ai, model_path=None, replay_path=None)
        Build Tk window, canvas, overlays, labels; initialize live env or replay; optionally load MaskablePPO model.
    reset_env()
        Reset live environment to fresh state.
    record_episode(max_steps=200)
        Run a new episode (model-driven if loaded, otherwise random legal actions) and cache replay for browsing.
    model_move()
        Single deterministic model step in live mode (uses action mask).
    jump_replay(delta) / play() / pause()
        Navigate or auto-play recorded timeline; speed controlled by slider.
    toggle_tiger_ai()
        Switch greedy <-> smart tiger in live env and refresh UI labels.
    load_model_from_entry() / browse_model()
        Load MaskablePPO model from text entry or file dialog; updates label.
    on_canvas_click(event)
        Handle human goat placements/moves; highlights legal moves; applies action to env.
    _apply_action(action_flat)
        Core executor for goat move + tiger response, updates rewards/labels/board, handles terminals.
    run()
        Start Tk mainloop.

NOTES
    - Uses env_goat_falcon.TnGEnv + FlattenTnGActionWrapper with action masking (same mask shape as training).
    - Loads MaskablePPO lazily if available; GUI still works without SB3 installed.
    - Replay JSON format expects a "timeline" list of {before, action, reward?, info?} entries; optional "final"/"result".
