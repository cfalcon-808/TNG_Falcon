# ============================================================
# VARIATION KEY REFERENCE
# ============================================================
#
# This file shows examples for the VARIATIONS dict used by train_abc.py.
#
# A variation can be either:
#   1) a single dict  -> one training phase
#   2) a list of dict -> multi-phase curriculum that continues the same model
#
# Core phase/control keys:
#   "timesteps"
#       Number of training timesteps for this variation or phase.
#       If omitted in train_abc.py, it falls back to TIMESTEPS.
#
#   "opponent_ai"
#       Main opponent selector used by the runner.
#       For goat learner runs, use OPP_TIGER_GREEDY or OPP_TIGER_SMART.
#       For tiger learner runs, use OPP_GOAT_RANDOM or OPP_GOAT_MODEL.
#
#   "tiger_ai"
#       Legacy alias for opponent_ai.
#       Only kept for backward compatibility; prefer opponent_ai.
#
#   "mix_prob"
#       Enables mixed opponents on episode reset.
#       Goat learner: probability of smart tiger, otherwise greedy tiger.
#       Tiger learner: probability of model goat, otherwise random goat.
#       Use None for a fixed opponent.
#
#   "checkpoints_per_run"
#       How many checkpoints to save during this variation/phase.
#       If omitted, train_abc.py uses CHECKPOINTS_PER_RUN.
#
#   "goat_model_path"
#       Path to a saved goat model. Only relevant when the opponent side uses
#       OPP_GOAT_MODEL or mixed goat opponents for tiger-learner training.
#
#   "reward_weights"
#       Optional nested dict of reward overrides.
#       In practice, train_abc.py also accepts reward override keys directly
#       in the variation dict, and treats all non-control keys as reward_weights.
#       Because of that, most runs can leave this as None and just place reward
#       keys alongside timesteps/opponent_ai.
#
# Reward/config override keys:
#   Any extra keys not listed above are passed into the environment as
#   reward/config overrides. These map to DEFAULT_KNOBS in env_tng_abc.py.
#   Examples: REWARD_BLOCK_TIGER, REWARD_BUBBLE_SPACE, MAX_TURNS,
#             REWARD_REPEAT_STATE, BASE_TIGER_CAPTURE_BIAS.
#
# Usage notes:
#   - Use None to inherit the defaults from train_abc.py / env_tng_abc.py.
#   - Use a list of phase dicts when you want curriculum training.
#   - Each phase can change opponent_ai, mix_prob, timesteps, and rewards.
#
