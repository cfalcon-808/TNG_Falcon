# ============================================================
# VARIATION KEY REFERENCE
# ============================================================
#
# This file shows examples for the VARIATIONS dict used by train_abc.py.
#
# A variation can be either:
#   1) None       -> one default single-phase run
#   2) dict       -> one training phase
#   3) list[dict] -> multi-phase curriculum that continues the same model
#
# Supported control keys:
#   "timesteps"
#       Number of training timesteps for this variation or phase.
#       If omitted, train_abc.py falls back to TIMESTEPS.
#
#   "opponent_ai"
#       Opponent selector used by the runner.
#       Goat learner: OPP_TIGER_GREEDY or OPP_TIGER_SMART
#       Tiger learner: OPP_GOAT_RANDOM or OPP_GOAT_MODEL
#
#   "mix_prob"
#       Enables mixed opponents on episode reset.
#       Goat learner: probability of smart tiger, otherwise greedy tiger.
#       Tiger learner: probability of model goat, otherwise random goat.
#       Use None for a fixed opponent.
#
#   "checkpoints_per_run"
#       How many checkpoints to save during this phase.
#       If omitted, train_abc.py uses CHECKPOINTS_PER_RUN.
#
#   "goat_model_path"
#       Path to a saved goat model. Only relevant when the opponent side uses
#       OPP_GOAT_MODEL or mixed goat opponents for tiger-learner runs.
#
# Tuning knobs:
#   Any other keys are passed directly into env_tng_abc.py as overrides for
#   DEFAULT_KNOBS. Examples: REWARD_BLOCK_TIGER, REWARD_BUBBLE_SPACE,
#   MAX_TURNS, REWARD_REPEAT_STATE, BASE_TIGER_CAPTURE_BIAS.
#
# Usage notes:
#   - Use None to inherit train_abc.py and env_tng_abc.py defaults.
#   - Put each tuning knob directly in the phase dict.
#   - Legacy keys such as tiger_ai and nested reward_weights are not supported.
#
